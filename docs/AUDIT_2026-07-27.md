# Audit keseluruhan KomikStream — 2026-07-27

Status: development-only. Audit ini membaca source aktif, route manifest, schema/migration, CI, dokumentasi, dan menjalankan quality gates di worktree saat audit.

## 1. Ringkasan eksekutif

KomikStream sudah berjalan sebagai React Router 7 framework app dengan SSR, PostgreSQL/Prisma, Clerk, iPaymu, Web Push, dan sumber data Sanka. Core public flow sudah dapat diuji lokal: katalog Sanka, detail manga, short chapter URL, dan reader.

Kualitas saat ini:

- Build/typecheck/test: hijau.
- Public SSR/API smoke test: hijau untuk route development utama.
- Visual screenshot: diverifikasi memakai Chromium headless fallback karena Hermes browser screenshot backend timeout pada local dan external URL.
- Authenticated flow: belum E2E karena Clerk development keys belum disediakan.
- Payment/push flow: belum E2E karena credential sandbox/VAPID belum disediakan.
- Production readiness: belum target; security/dependency/migration items di bawah dicatat, bukan alasan menghentikan development UI.

## 3. Arsitektur aktual

### Runtime

```text
Browser
  -> React Router 7 SSR loader/action
  -> route UI / server library
  -> Prisma 7 + PostgreSQL

Sanka API
  -> development seed
  -> Komik.chapters metadata JSON
  -> KomikChapter.images JSON untuk cache chapter
  -> reader fallback fetch jika cache gambar kosong
```

### Route count

`app/routes.ts` memiliki 25 route entries (24 explicit `route()` calls + 1 `index()` root):

- 16 public/page routes, termasuk root, manga, detail, short chapter route, compatibility chapter route, auth, legal, account.
- 9 API routes di bawah `/api`.

Short public chapter URL adalah `/:chapterId`; `/chapter/:chapterId` dipertahankan sebagai compatibility URL.

### Server/client boundary

- `*.server.ts` hanya boleh diimport dari `loader`, `action`, atau server-only code.
- `app/lib/manga-types.ts` berisi type/parser murni agar dapat dipakai route component tanpa menarik server module ke client bundle.
- `app/lib/manga.server.ts` berisi fetch Sanka server-side dan image parser.
- `MangaReader.tsx` adalah client-interactive component: progress, keyboard, mode baca, IntersectionObserver.

- `subscription.server.ts`: status/activation/expiry/cancel state.
- Production concern: webhook state machine masih perlu integration test dan audit ordering/locking sebelum live payment.

### Push

`push.server.ts` menyimpan endpoint setelah ownership check. Subscribe/unsubscribe route memakai auth mapping dan same-origin mutation guard. VAPID kosong berarti feature disabled.

## 5. Temuan terverifikasi

### High — dependency advisories

`pnpm audit --prod --json` menemukan:

- `react-router@7.18.1` — advisory high, berlaku pada unstable RSC path; project memakai framework SSR route API, tetapi upgrade/impact review tetap diperlukan sebelum production.
- `fast-uri@3.1.3` — host confusion; transitive Prisma dev path, patched `3.1.4`.
- `@hono/node-server@1.19.11` — two moderate advisories, transitive Prisma dev path.
- `valibot@1.2.0` — moderate advisory, transitive Prisma dev path.

Development impact: tidak memblokir local UI. Production action: update Prisma/RR7 dependency tree dan rerun audit.

### High — destructive historical migration

`prisma/migrations/2_sprint_4_add_ipaymu_subscription/migration.sql:10-121` drops old columns/tables (`Anime`, `SyncLog`) and changes required fields without backfill. Jangan rewrite migration jika pernah applied. Development DB disposable; deployment DB belum diverifikasi.

### Medium — health endpoint detail

`app/routes/api.health.ts:6-22` exposes timestamp, uptime, package version, DB status, and response time. Useful for development diagnostics; reduce output or protect it before public deployment.

### Medium — Sanka remote dependency

`app/lib/manga.server.ts:18-36` fetches a remote Sanka URL from a server loader fallback. Chapter ID is encoded, but response availability and upstream latency directly affect reader response. Add timeout/cache/failure telemetry before production.

### Medium — payment integration test gap

`app/routes/api.subscription.webhook.ts:24-73` has code-level validation and status mapping, but no signed payload + real database regression test. Replay, out-of-order status, concurrent callback, and owner mismatch remain unproven in runtime.

### Low — docs drift found and corrected in this audit

- Architecture previously described homepage as static and omitted Sanka/short route details.
- Architecture described only basic manga metadata.
- Old docs still contain Next/KuroManga-era intent. They are now explicitly classified as historical requirements, not source of truth.
- `MangaReader` old `'use client'` directive is no longer present after current cleanup; route/module docs now describe RR7 boundary instead.
